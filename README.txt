ROYAL STAY — PROFESSIONAL MULTI-PAGE WEBSITE

Pages:
- index.html        Home
- rooms.html        Rooms & Suites
- experience.html   Features, wellness, dining, pool and concierge
- gallery.html      Photo gallery
- contact.html      Contact and booking enquiry

Preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Keep the assets folder beside the HTML pages.

Image reliability:
- Hotel photography uses Unsplash URLs and requires an internet connection.
- Each image has an error handler and falls back to assets/images/image-fallback.svg instead of a broken-image icon.
- If your browser/network blocks Unsplash, replace the URLs with licensed images saved locally in assets/images.

Important:
- The booking form is front-end only and displays a confirmation message. Connect it to a backend/email/booking provider to receive real enquiries.
- Contact details and room rates are sample content; verify before publishing.
